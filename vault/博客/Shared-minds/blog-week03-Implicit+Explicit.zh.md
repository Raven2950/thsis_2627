### Left
和别人合作时，比起截图，我更想收到 Google Doc；比起 JPEG，我更想收到 Illustrator 文件；比起 MP3，我更想收到 MIDI。因为截图、JPEG 和 MP3 都是“压扁”的，它们只记录了某样东西在某个固定的最终状态下看起来或听起来是什么样，我没法轻松地编辑里面的单个部分。相反，Google Doc、Illustrator 文件和 MIDI 储存的是**可寻址、可重新排列的离散部件**。合作者可以改 MIDI 里的一个音符、挪动 Illustrator 里的一个矢量形状，或者重写 Google Doc 里的一段话，而不会毁掉整个作品。这打开了真正的对话：双方可以提出局部修改，尝试不同方案，一起把想法搭起来。

把内容拆成独立的、可寻址、可重排的积木，是 Pinker 的**离散组合系统**和 Deutsch 的**跃迁至普遍性**背后的核心逻辑。它不是把元素混在一起让它们失去各自的身份（像调颜料那样），而是让每个单元保留自己的意义，可以按照简单的规则被重新排序、替换、删除或重组。这个机制打开了一个巨大的“表达空间”：从一小组有限的基本部件出发，可以生成数量巨大、几乎无限的全新输出。人类语言正是这样运作的：有限的词通过句法组合，产生无穷的新句子，远远超过任何人事先能记住的数量。DNA 遗传密码也基于同样的原理，用四种核苷酸积木编码出无数不同的生命。通用数字计算机是“跃迁至普遍性”的另一个重要例子：它由简单的开关组成，却几乎可以模拟任何物理过程。

批评者可能会说，用固定的预制部件来搭建，太像“按数字填色”了，好像创造力被现成的积木限制住了。确实，你受限于手头有的部件。但这种批评误解了这些系统的运作方式。离散组合系统并不会把你逼进少数几个预设的结果里。它的力量在于重组：即使基本部件不变，新的排列也会产生新颖、意想不到的结果。

这个强大的组合思想，给视觉媒介提出了更难的问题。词语和 DNA 天然适合离散组合的规则，但图像通常被当作连续的、混合在一起的整体。不过，我们仍然可以想象一种建立在可寻址、可改变部件之上的视觉语言。想象一幅风景，它可以修改的离散部件包括：天空的颜色、云的形状和位置、光照方向、树的种类和摆放、地面质感、动物形象，以及前景里的物件。我们可以设计一套简单的视觉句法：树必须立在地面图层上；光源决定阴影方向；云飘在地形上方。每个元素都保持独立，可以被替换、移动或删除，而不会毁掉整个画面。这就是我们发明的一种视觉组合语言。

我们还可以把这个逻辑延伸到动态影像和电影。传统电影通常被“压扁”成完成的视频帧，就像一张 JPEG。但想象一种“没被压扁”的电影媒介：它储存的不只是渲染好的像素帧，而是离散的、可复用的部件——角色模型、道具、灯光设置、背景环境、镜头运动和音轨。每个部分在创作完成后都还能编辑。合作者可以挪动一个角色、改变灯光的时间、替换背景场景，或者调整镜头角度，而不需要从头重拍。这很像现在的实时 3D 引擎，但被推得更远，成为一种通用的创作媒介。它会让电影从一个固定的、被记录下来的陈述，变得更像人类语言：开放、可重组，能够持续地对话和修改。


### Right
我们知道的很多东西，没法被写成清楚的事实或规则，这叫隐性知识。比如听懂一个笑话、对另一个人产生共情、读懂一个社交场合，这些我们自然而然就会做，但很难为它们写出一步步的说明。这和 McGilchrist 关于大脑理解世界的两种方式的观点相吻合。

左脑的“使者”（Emissary）模式处理显性知识：它把事物拆成独立、可复用的部件，遵循清晰的规则。右脑的“主人”（Master）模式关注整体、语境和细微的人类情感。McGilchrist 说，这种右脑的整体式观看在现代生活中被低估了，尽管它带给我们生命中许多最有意义的体验。我大体同意他。共情、幽默和读懂没说出口的社交暗示，确实没法完全被简化成简单的规则。不过，整体式的直觉也并不完美，它可能有偏见、会出错，所以我们仍然需要逻辑和分析去检验它。两种思考方式单独都不够好。

传统计算机非常适合 Pinker 和 Deutsch 所说的左脑风格。老式代码依靠清晰的“if-then”规则运行，重新排列独立的小部件。但计算机很难处理那些模糊的、依赖语境的、需要右脑式整体思考的东西。没有大量手写的规则，它们没法自然地理解讽刺、微妙的情绪或者复杂的现实情境。

这就引出了 McGilchrist 的担忧：计算机可能会让我们的文化失衡变得更严重。我们的社会本来就喜欢把东西拆成模块化、可重组的部件。传统计算奖励这种思考方式，把整体的、杂乱的、依赖语境的判断推到一边。我们有可能把自己简化、拆碎之后的“地图”当成真实世界本身。不过，计算机只是工具，伤害来自人们选择如何使用它们，而不是计算本身。

现代机器学习不只依赖写死的“if 语句”。它在海量数据中寻找隐藏的规律和联系。这能让我们更接近右脑那种整体式的方式吗？大语言模型学习的是词与词之间的关系，但真实世界不是由词构成的。LLM 听起来可以很有道理，但它们并不真正理解现实中的身体经验。扩散模型学习像素之间的关系，可以生成非常逼真的图像。即便如此，它们处理的只是像素数据，并没有像人一样真正“看见”或理解一个场景。它们能产出看起来浑然一体的结果，但这不是真正的整体理解。

即使有这些局限，机器学习还是给了我们一个有趣的中间地带。AI 可以在杂乱的现实数据中寻找有用的、可重组的特征，类似左脑的拆解方式；然后生成模型可以把这些部件重新拼成完整、可信的整体。理论上，这能让我们同时得到两种方式的好处：离散重组的力量，以及完整、有语境的整体感。

但目前 AI 只是在寻找统计规律。它可以模仿出看起来像人类整体思考的结果，却没有真正的共情、洞察或意义感。机器学习可以为我们做出更好的工具，但它没法修复我们社会在狭窄分析和整体思考之间的失衡。

这次的 making 是从上周的作品发展来的。

上周的版本主要是文字：我想看看面对同一个主题词，AI 和人的联想能有多不一样。用户输入一个词，写下自然想到的三个联想；DeepSeek 的 API 为同一个输入生成另外三个联想；人和 AI 的联想一起出现在屏幕上。

做完第一版之后，我觉得把词固定在两列里太受限了。所以我加入了自由拖拽、多选和重新排列。用户可以把人和 AI 的联想拖过中线，放在共享画布的任何地方。词本身没有变，但它们之间的空间关系可以彻底改变整个画面的意义。

这让我想到“狗咬人”和“人咬狗”的区别：元素几乎一样，但顺序和关系造成了完全不同的意思。在这个项目里，位置起到了类似语法的作用。一个词放在另一个词的上面、下面、旁边，或者和它重叠，都可能暗示不同的动作或关系。

我受到 Threads 上一个帖子的启发，想加一个 Mix 功能。用户可以选中几个词，把它们当作一幅视觉草图，词的位置是有意义的。我没有直接把这些词发给图像模型，而是先让 DeepSeek 去理解这些词和它们的空间关系，由 DeepSeek 生成一个新的图像提示词，再把这个提示词通过 Replicate 代理发给 Flux 模型，根据这个排列生成一张新图。（这里用了两个 agent 来完成。）

画布上的每一项都存成一个 JSON 对象，包含这一项的文字或图片、来源、位置、旋转、图层、动画和类型。整个画布由一个 JavaScript 数组控制。拖拽、删除、动画和混合，都是先修改这个数据结构，再重新渲染页面。这个 JSON 也会存到 localStorage 里，所以刷新页面之后排列还能恢复。

但有时候它真的会给我生成很蠢的图。

我感觉 AI 很难理解形容词，或者把形容词转化成合适的视觉元素，有时候它会直接把这个词本身印在拼贴里。
