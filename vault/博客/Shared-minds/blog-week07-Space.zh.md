## My Writing

空间确实能帮我思考，但不是因为它让我_看见_，而是因为它让我_定位_。整理毕设资料的时候，我用过一张关键词地图。概念之间本来没有物理距离，可一旦我把它们放在画布上，我就开始记得“那个想法在左下角，靠近_失明_”。位置变成了提取记忆的钩子，这正是 Foer 说的记忆宫殿。

但因为我在做无障碍相关的研究，我一直注意到：当我们说“空间”时，通常指的是**视觉空间**。盲人也有很强的空间感，它由声音、触觉、移动和时间构成。这让我觉得，空间并不是“眼前的三个维度”，而是一种关系：知道某样东西在哪里，以及怎样回到那里。这样看的话，高维的数学空间和身体所在的空间并不矛盾，两者讲的都是“靠近”和“路径”。

在电影和 VR 之间，我更喜欢电影的剪辑。思考不是一段连续的行走，而是一次跳跃，一个联想就能把你带到很远的地方。我很认同“通过创造来导航”的想法：不是在一个已经存在的世界里行走，而是每一个念头都召唤出一个新的空间。

至于 80 亿个平行宇宙，embedding 空间提供了一种可能。如果每个人的念头都住在同一个空间里，那么在我的任何一个想法周围，可能都有怀着相似想法的陌生人。空间里的一个位置，就变成了一个和别人相遇的地方。

### 记忆墓穴 The Memory Crypt

记忆墓穴是一个在浏览器里的小型 3D 记忆宫殿。你输入需要记住的东西，AI 用石头和蜡把每一样雕出来，放进一座烛光墓穴的壁龛里。然后蜡烛熄灭，你得记起什么东西在哪里。

### 它是怎么来的

这个项目来自那场 TED 演讲。Joshua Foer 解释说，记忆冠军并没有特殊的大脑，他们用的是位置记忆法：把每样东西放在一个你熟悉的地方，并让画面变得荒诞。我们的大脑不擅长记清单，却很擅长记地点和画面，所以诀窍在于翻译。

所以我把记忆宫殿当成一个界面来做。我身上那个“线虫”的部分，得到了一个可以转身环顾的房间；而那个会处理符号的部分，可以决定房间里放什么。

### 故事

你是一个容易被遗忘的地窖看守人，站在一间圆形石室的中央。四周的墙上有 5 到 7 个编了号的壁龛，每个都点着一支蜡烛。

你输入一串需要记住的东西。

LLM 把每一项变成一个荒诞的画面，用 three.js 的基本几何体把它拼出来。

每个物件被放进一个壁龛，旁边配着一段手写的描述。你用鼠标转动视角，把它们记下来。

点击“熄灯”，蜡烛一支接一支地熄灭，物件随之消失。

回忆阶段：蜡烛又一支接一支地亮起，但壁龛是空的。你需要输入原来放在那里的东西。答对了，物件就会重新出现。

### 怎么做的

整个作品是一个用 three.js 写的 HTML 文件，没有构建步骤。最关键的有三部分。

**外观。** 视觉风格上，我借鉴了低多边形的独立恐怖游戏：极低的分辨率、很少的颜色、大量的抖动（dithering）。场景以 230 像素的高度渲染到一张离屏纹理上，然后一个着色器把每个像素映射到三条色带之一（冷青色、暖深红、烛光金），并用有序 Bayer 图案加上抖动效果。正因为这样，模型可以做得非常粗糙，大部分工作由着色器和烛光完成。

**AI 雕刻师。** 按照这周“让模型来建造世界”的提示，每一项都会通过 ITP 的 Replicate 代理发给一个 LLM。模型返回的不是图片，而是一份 JSON 格式的几何体清单：球体、立方体、圆柱、圆锥、圆环、胶囊，每个都带着颜色、位置、缩放和旋转。页面把它们组装起来，缩放到适合底座的大小，再加上缓慢的待机摇摆。所有项目是并行发送的，所以它们会一个接一个地出现，而不是全部等到最后才出来。
