# OC 角色卡（第一稿）

> 这一页全部是**草稿**。名字、年龄、关系都可以改。标了【待定】的地方是要我自己决定的。
> 写法参考小红书上做 OC 的格式：基础信息 → 外貌 → 性格（表 / 里）→ 喜欢 / 讨厌 → 小习惯 → 说话方式 → 背景 → 关系。另外加了两栏是游戏需要的：**他在每天的循环里做什么**，以及**他绝对不会说的话**（防 OOC 用）。

---

## 0. 世界卡

| | |
|---|---|
| **时间** | 2016 年前后，春天到夏天（回南天 → 梅雨 → 台风季） |
| **地点** | 广州一个城中村，名字待定（先叫"涌边村"） |
| **关键词** | 握手楼、一线天、回南天、祠堂、菜市场、士多店、报刊亭、电动车、出租屋、天台 |
| **代表色** | 发霉的青绿、瓷砖白、夜里的霓虹粉 |
| **天气** | 回南天：墙在出水，纸会软，字会洇开；台风天：特殊的一天 |
| **一句话** | 一个正在等拆迁的村子，和一个每天都在把自己忘掉的人 |

**设定要点**

- **村子要拆了。** 墙上贴着旧改公告，倒计时 N 天。这是表层的期限：在村子被拆之前，他得想起来（或者决定不想起来）。城市和主角一起在失忆。【待定：要不要用拆迁做期限】
- **十年前的手机**：已经普及，但还没那么无所不能。他的手机被锁着、被收走，或者不可信（见主角卡）。
- **报纸还在卖**：楼下报刊亭有《广州日报》《羊城晚报》，还有满墙的小广告、租房启事、补习班传单。鬼能圈的字都从这里来。
- **语言**：家里说粤语，外面说普通话，补习班上说"标准普通话"。【待定：游戏里用多少粤语】

## 1. 主角

| | |
|---|---|
| **名字** | 梁知明（"知明"：想要知道、想要清楚，却每天都在起雾）【待定】 |
| **年龄** | 26 岁（1990 年生） |
| **性别** | 男【待定】 |
| **职业** | 城中村里一个小补习班的数学老师，教小学生奥数 |
| **代表物** | 草稿纸、2B 铅笔、起雾的眼镜（近视） |
| **代表色** | 灰白，像受潮的纸 |
| **一句话印象** | 一个曾经被所有人期待的人，现在每天醒来都不知道自己是谁 |

**外貌**

- 偏瘦，头发有点长没剪，眼镜片上总有一层雾。
- 穿得很整齐，衬衫扣到最上面一颗。即使什么都不记得，他的身体还记得要"像样"。

**性格**

- **表**：礼貌、安静、很有条理，像一个好学生。
- **里**：极度需要确定的答案。一件事没有答案，他会一直想，想到睡不着；给出一个答案，又马上自己否定掉。100% or nothing。

**喜欢 / 讨厌**

- 喜欢：答案唯一的题、整齐的桌面、清晨（因为什么都还没发生）。
- 讨厌：模棱两可的话、被人问"你还好吗"、潮湿。

**小习惯（和玩法有关）**

- **睡前一定会把桌上所有东西收进抽屉。** 笔、纸、报纸，全部收好。这是他控制生活的方式，也是鬼最大的障碍：**他自己的"想要可控"，在挡住他的记忆。**
- 紧张的时候会开始数数，或者在纸上演算没有意义的式子。

**说话方式（声音卡）**

- 句子短，精确，爱用数字和"首先、其次"。
- 遇到不知道的事，会先给一个答案，再加一句"应该是"。
- **他绝对不会说的话**：
  - "我不知道。"（他宁可说错，也不说不知道）
  - "算了。"
- 样板台词（草稿）：
  - "现在是七点十二分。我在一个房间里。房间很潮。这些是确定的。"
  - "这张纸上的字不是我写的。……应该不是。"

**背景（设计者层，玩家不会一次看到）**

- 小时候是奥数竞赛生，拿过奖，是老家那条街的骄傲。"伤仲永"这三个字，他小时候在作文里写过，是用来批评别人的。
- 后来没能成为大家期待的那种人。【待定：具体发生了什么】
- 手机里的朋友圈还停在"准备读博 / 出国"的状态，那是他经营出来的自己。

**他在每天的循环里做什么**

- 表层要追的事：【待定】可能是一道他一直没解出来的题、一个他要找的人，或者手机的密码。
- 每天醒来，他都会认真地、从零开始，试图把自己弄清楚。

**关系**

- 和照顾他的人：依赖，又说不清的抗拒。
- 和鬼：他不知道鬼的存在，只看到"不是自己写的字"。

## 2. 鬼

| | |
|---|---|
| **名字** | 没有名字（玩家操控的存在）【待定：是否在结尾揭示】 |
| **形态** | 水渍、雾气、镜子上的手印。回南天的时候最强 |
| **代表色** | 透明，带一点青 |
| **一句话印象** | 唯一记得一切的那个，但说不出话 |

**能做什么 / 不能做什么**

- 能：碰纸、圈字、翻书、挪动轻的东西；在"某些地方"白天完全接管主角的身体。
- 不能：说话、碰触摸屏（没有温度，手指不导电）、拿动重的东西、用主角收进抽屉里的东西。

**鬼是谁（设计者层，先列可能）**【待定】

- 主角过去的自己；
- 一个已经不在的人；
- 主角心里那个永远不会忘记、一直在追问的部分（追问者）。

**它想要什么**

- 【待定】它想要的不一定和主角一样。它想让他想起来，可能是出于爱，也可能是出于不甘心。

**声音卡**

- 鬼不说话。它的"声音"就是它能用的字：报纸上的标题、补习班传单上的口号、租房启事里的电话号码。
- 它的语气，来自它当晚凑得出来的字，所以经常是破碎的、错位的，像勒索信。

## 3. 收走东西的人（照顾他的人）

| | |
|---|---|
| **身份** | 【待定】母亲，或者另一个"以爱为名控制他"的人（亲戚、房东、前任） |
| **年龄** | 五十多岁（如果是母亲） |
| **代表物** | 一串钥匙、保温壶 |
| **一句话印象** | 每天晚上把他的笔和手机收走，说"为你好" |

**性格**

- **表**：勤快、唠叨、什么都替他安排好。
- **里**：她知道发生过什么。她觉得他忘了比较好，或者觉得他应该按她希望的方式记住。

**在循环里的功能**

- 每晚来收拾房间，收走手机、笔，有时也会扔掉"乱七八糟的纸"。
- 她是鬼最大的障碍之一，也是知道真相的人。

**声音卡**

- 粤语和普通话混着说，问句很多："食咗饭未？""今日有冇乖乖食药？"【待定：要不要有"吃药"这条线】
- **她绝对不会说的话**："对不起。"
- 样板台词（草稿）：
  - "唔使谂咁多啦，你记得食饭就得啦。"（不用想那么多，你记得吃饭就行了）

## 4. 城中村里的人（草稿，2–3 个）

### 士多店 / 报刊亭的阿伯

- **功能**：每天卖报纸。**他进了什么报纸，就决定了今晚鬼能用哪些字。**
- 每天都对主角讲同一个笑话，因为主角每天都会笑。
- 声音：粤语，慢，爱讲村子以前的事。

### 对面握手楼的邻居

- **功能**：主角每天都把她当成陌生人，但她记得一切。她是这个游戏里的"Kim"：不审判，会在他搞砸的时候给一点同情。
- 做夜班（比如便利店收银），所以作息和主角错开，经常在天台或楼梯间遇到。
- 【待定】她知道多少，她和过去的主角是什么关系。

### 补习班的学生

- **功能**：一个十岁左右的小孩，奥数很好，被父母寄予厚望。是"下一个伤仲永"。
- 主角每天都重新认识他，但小孩会注意到老师留在草稿纸上的奇怪的字。
- 他让"期待"这件事在下一代身上重复了一次。
