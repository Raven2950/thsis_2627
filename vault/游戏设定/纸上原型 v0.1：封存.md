# 纸上原型 v0.1：封存

> 目的：用最少的规则，在纸上跑三天，看"玩家到底怎么玩"能不能成立。
> 所有名字、物件、数字都是临时的，只为了让规则跑起来。

## 一句话：玩家在做什么

**玩家是那个被封存的她。** 白天借她的空闲时间活一会儿，晚上用她留在外面的东西给她留话，让她一点点认出自己以前写过、爱过的东西。她每晚睡着，封印就会重新合上，只有互相连得上的记忆才留得住。

---

## 规则（一共 6 条）

**1. 两种记忆**
- **日常记忆**：工作、妈妈、街坊、怎么去补习班。**永远不会忘。**
- **封存记忆**：一切和"那个想当小说家的她"有关的东西。每件封存的物件都有两面：
  - 正面：她现在怎么看它（"一箱旧纸，该拿去回收了"）；
  - 背面：真相（"这是她大学时写的小说草稿"）。
  - 她**认出**一件物件，就是把它翻到背面。

**2. 一天分五段**

| 时段 | 谁在动 | 玩家能做什么 |
|---|---|---|
| 早上 | 她 | 看她读到昨晚的痕迹，看她信不信 |
| 日常（上课、吃饭） | 她，自动 | 只能看。很短的场景 |
| **空闲时间** | **玩家操控她** | **3 个行动点**：去一个地方 / 看一样东西 / 和一个人说话 / 用一样东西 |
| 睡前 | 她，自动 | 只能看她收拾房间 |
| **夜晚** | **玩家是鬼** | **2 条痕迹**：圈字 / 翻页 / 挪动一样轻的东西 |

**3. 睡前收拾（她的习惯）**
- 她会把桌上的东西全部收进抽屉，**只有今天用过的东西会留在桌上**（报纸读了一半、书摊开着）。
- 所以，玩家想让鬼晚上有什么工具，**白天就要让她用一下那样东西**。
- 收进抽屉的东西，鬼拿不动。

**4. 鬼的工具 = 桌上的东西**
- **报纸**：只能圈当天报纸上有的字。每天的报纸不一样，所以每晚能"说"的话不一样。
- **书**：翻到某一页，或者圈书里的字。
- **轻的东西**：照片、钥匙、一张纸，可以挪一个位置。
- **笔**：只有笔留在桌上时，才能直接写字，最多写 4 个字。

**5. 认出**
早上她读到痕迹时：
- 痕迹能**指向一件她看得到、碰得到的物件** → 当天空闲时间里，这件物件会多出一个新选项（"翻开看看"、"认一认字迹"）。玩家用了这个选项，她就**认出**它（翻到背面）。认出的东西会**有颜色**，其余的仍是黑白灰。
- 痕迹太模糊，指不到任何东西 → 她只会疑惑："谁圈的？"
- 痕迹让她觉得可怕或不可信（比如出现在奇怪的地方）→ 她会把那样东西收起来。

**6. 封印（每晚刷新）**
- 每晚她睡着，**今天认出的东西会被重新封上**，第二天早上又变回黑白，除非：
  - **两件认出的东西连得上**（比如手稿和书页边的批注是同一个字迹）：它们会保留 **2 天**；
  - **三件连在一起**：这段记忆**不再被封上**，封印松了一格。
- 封印松得越多，她能想起的就越多，能去的地方也越多。

**期限：** 墙上贴着拆迁公告，**第 7 天**签约截止。（纸上原型只跑前 3 天。）

## 跑一遍：第 1 天到第 3 天

### 第 1 天

**早上。** 她醒来，房间是黑白灰的。玩家和她一样，什么都不知道。内心声音很冷："七点十二分。今天三节课。"

**日常。** 上课。一个学生问她："老师，你小时候就想当数学老师吗？"她自动回答："对啊。"（玩家只能看。）

**空闲时间（晚饭后，3 个行动点）。** 玩家第一次能操控她。
1. 看床底的纸箱 → "一箱旧纸，周末拿去回收。"（没认出）
2. 下楼找报刊亭阿伯买报纸，顺便读了一会儿 → **报纸算"用过"**
3. 翻书架上的《西西弗神话》 → "高中时买的吧。"（没认出）

**睡前。** 她把笔收进抽屉。报纸读过，留在桌上。

**夜晚。玩家第一次发现自己是鬼。** 桌上只有报纸。2 条痕迹。

玩家想告诉她：床底的箱子是你写的。报纸上能圈的字里有 `你` `写` `过` `床` `下`，**也有** `旧书` `回收`。

> 这是第一个真正的选择：
> - 圈 `你写过` + `床下` → 指向纸箱。
> - 不小心或者故意圈了 `旧书回收` → 她第二天可能真的把箱子扔了。
> - 只圈 `别` `扔` → 她会疑惑"别扔什么？"，什么都指不到。

假设玩家圈了 `你写过` 和 `床下`。

### 第 2 天

**早上。** 她看到报纸上被圈出来的字："你写过……床下。"内心声音："谁圈的？……昨晚自己圈的吧。"痕迹指向纸箱 → **今天纸箱多了一个选项："翻开看看"。**

**日常。** 和妈妈吃午饭。妈妈说拆迁款下来后要先还家里的债，"你那些旧东西，搬家前都扔了吧"。（期限开始压过来。）

**空闲时间（3 个行动点）。**
1. 翻开纸箱 → **认出：小说草稿《回南天》**。纸箱有了颜色。她读了第一页：一个女孩在回南天里等一艘渡轮。
2. 再看书架上的《西西弗神话》 → 因为刚刚认得了手稿的字迹，**她注意到页边批注是同一个字迹** → **认出：那本书**。
3. 把手稿放到桌上读 → 手稿算"用过"。

**两件认出的东西连上了（同一个字迹）** → 它们会保留 2 天。

**睡前。** 她收拾房间，手稿和书都留在桌上（用过）。笔又被收进了抽屉。

**夜晚。** 鬼有了新工具：**她自己的手稿**。

> 第二个选择：鬼可以继续圈报纸上的字（别人的话），也可以**圈她自己手稿里的字**（她自己的话）。
> 用她自己的字说话，可能更容易让她相信，但手稿里的字很少，说不了太具体的事。

假设玩家在手稿里圈了 `渡轮`，在报纸上圈了 `别` `扔`。

### 第 3 天

**早上。** 手稿和书还有颜色（连上了，保留 2 天）。她看到"别扔"和"渡轮"。"渡轮"指向哪里？房间里没有渡轮 → **它指向一个新地点：江边的渡口**。今天空闲时间能去那里。

**日常。** 妈妈来她出租屋，帮她"收拾"。**如果手稿还在桌上，妈妈会把它装回纸箱，说"这些搬家前扔掉"。**（这里可以测试：玩家会不会后悔让她把手稿留在外面？）

**空闲时间。** 去渡口。在那里，鬼可以**短暂接管她**（"某些地方"）：玩家直接操控她，不受记忆限制，在渡口的长椅下找到一样东西……（第 3 天以后的内容先不写。）

**反面例子：如果第 2 天只认出了手稿、没有认出书。** 第 3 天早上，手稿又变回黑白："这是什么？"她把它塞回纸箱。玩家会很直接地感到"白干了"，这就是"封印每晚合上"的分量。

## 怎么在纸上跑

**需要准备：**
- 物件卡：正面写她的看法，背面写真相。
- 每天一张"报纸字条"：把能圈的字剪成小纸条。
- 两个区域：**桌上**、**抽屉**。
- 标记：3 个行动点、2 个痕迹点、彩色贴纸（表示认出）。

**两个人：**
- **你演"她"和世界**：按规则说她的反应、决定她收拾什么、翻牌。
- **朋友演玩家**：白天花行动点，晚上留痕迹。
- 不要提前告诉朋友规则 3（睡前只留用过的东西），看他们自己能不能发现。

**跑完之后问朋友：**
1. 你知道你在扮演谁吗？什么时候知道的？
2. 晚上留什么，你犹豫了吗？为什么？
3. 第二天她没认出来时，你是什么感觉？
4. 哪一步你不知道该干什么？

## 跑这一遍发现的问题（待定）

1. **失败怎么算？** 如果玩家让她把箱子扔了，游戏是结束、绕路，还是这段记忆永远消失？
2. **"认出"的判断太依赖我当场说了算。** 做成游戏时要变成明确的规则，比如每件封存物件写好"哪几个字能指向它"。
3. **3 个行动点、2 条痕迹，够不够？** 要跑过才知道。
4. **日常的自动部分要多长？** 太短，"随波逐流"感不出来；太长，玩家会烦。
5. **妈妈收拾房间这件事**：只是一个事件，还是一条贯穿的线（她每次来都会收走一些东西）？
